Capítulo 9

Determinantes y operaciones elementales

Parcial 2 · Determinantes y vectores

Calcular un determinante 4×44\times44×4 por cofactores exige evaluar cuatro determinantes 3×33\times33×3, y cada uno de ellos tres determinantes 2×22\times22×2: doce productos y muchas oportunidades de equivocarse. Hay un camino mucho más corto. Como el determinante de una matriz triangular es simplemente el producto de su diagonal (Corolario 8.14), la estrategia es triangularizar la matriz con operaciones elementales de fila, controlando en cada paso cómo cambia el determinante. Este capítulo establece exactamente cuánto cambia.

9.1 Efecto de las operaciones elementales

Teorema 9.1 · Intercambio de dos filas

Sea A=(A1,…,Ai,…,Aj,…,An)A=(A_1,\dots,A_i,\dots,A_j,\dots,A_n)A=(A1​,…,Ai​,…,Aj​,…,An​) una matriz cuadrada de orden nnn. Si BBB es la matriz que se obtiene de AAA al intercambiar las filas iii y jjj, es decir B=(A1,…,Aj,…,Ai,…,An)B=(A_1,\dots,A_j,\dots,A_i,\dots,A_n)B=(A1​,…,Aj​,…,Ai​,…,An​), entonces det⁡ ⁣(B)=−det⁡ ⁣(A).\dt{B}=-\dt{A}.det(B)=−det(A).

Demostraciónmostrar

La idea es construir una matriz auxiliar con dos filas iguales, de modo que su determinante sea cero por el axioma A1, y luego desarmarla con los axiomas A2 y A3.

Sea C=(A1,…,Ai+Aj⏟fila i,…,Ai+Aj⏟fila j,…,An).C=(A_1,\dots,\underbrace{A_i+A_j}_{\text{fila }i},\dots,\underbrace{A_i+A_j}_{\text{fila }j},\dots,A_n).C=(A1​,…,fila iAi​+Aj​​​,…,fila jAi​+Aj​​​,…,An​). Como las filas iii y jjj de CCC son iguales, el axioma A1 da det⁡ ⁣(C)=0.(9.1)\dt{C}=0. \tag{9.1}det(C)=0.(9.1)

Ahora calculemos det⁡ ⁣(C)\dt{C}det(C) de otra manera. Aplicando el axioma A3 (aditividad) sobre la fila iii: det⁡ ⁣(C)=det⁡ ⁣(…,Aii,…,Ai+Ajj,… )+det⁡ ⁣(…,Aji,…,Ai+Ajj,… ).\dt{C}=\dt{\dots,\overset{i}{A_i},\dots,\overset{j}{A_i+A_j},\dots} +\dt{\dots,\overset{i}{A_j},\dots,\overset{j}{A_i+A_j},\dots}.det(C)=det(…,Ai​i​,…,Ai​+Aj​j​,…)+det(…,Aj​i​,…,Ai​+Aj​j​,…). Y aplicando A3 otra vez, ahora sobre la fila jjj de cada sumando, obtenemos cuatro determinantes: det⁡ ⁣(C)=  det⁡ ⁣(…,Aii,…,Aij,… )⏟= 0 (A1)  +  det⁡ ⁣(…,Aii,…,Ajj,… )⏟= det⁡(A)+  det⁡ ⁣(…,Aji,…,Aij,… )⏟= det⁡(B)  +  det⁡ ⁣(…,Aji,…,Ajj,… )⏟= 0 (A1).\begin{aligned} \dt{C}=\;& \underbrace{\dt{\dots,\overset{i}{A_i},\dots,\overset{j}{A_i},\dots}}_{=\,0\ \text{(A1)}} \;+\;\underbrace{\dt{\dots,\overset{i}{A_i},\dots,\overset{j}{A_j},\dots}}_{=\,\det(A)} +\;&\underbrace{\dt{\dots,\overset{i}{A_j},\dots,\overset{j}{A_i},\dots}}_{=\,\det(B)} \;+\;\underbrace{\dt{\dots,\overset{i}{A_j},\dots,\overset{j}{A_j},\dots}}_{=\,0\ \text{(A1)}} . \end{aligned}det(C)=​=0 (A1)det(…,Ai​i​,…,Ai​j​,…)​​+=det(A)det(…,Ai​i​,…,Aj​j​,…)​​+​=det(B)det(…,Aj​i​,…,Ai​j​,…)​​+=0 (A1)det(…,Aj​i​,…,Aj​j​,…)​​.​ El primero y el cuarto tienen las filas iii y jjj repetidas, luego valen 000 por A1. El segundo es exactamente det⁡ ⁣(A)\dt{A}det(A) y el tercero es exactamente det⁡ ⁣(B)\dt{B}det(B). Así, det⁡ ⁣(C)=det⁡ ⁣(A)+det⁡ ⁣(B).\dt{C}=\dt{A}+\dt{B}.det(C)=det(A)+det(B). Comparando con (9.1): det⁡ ⁣(A)+det⁡ ⁣(B)=0⟹det⁡ ⁣(B)=−det⁡ ⁣(A).\dt{A}+\dt{B}=0\qquad\Longrightarrow\qquad \dt{B}=-\dt{A}.det(A)+det(B)=0⟹det(B)=−det(A).

Teorema 9.2 · Sumar un múltiplo de una fila a otra

Sea A=(A1,…,Ai,…,Aj,…,An)A=(A_1,\dots,A_i,\dots,A_j,\dots,A_n)A=(A1​,…,Ai​,…,Aj​,…,An​) una matriz cuadrada de orden nnn. Si BBB es la matriz que se obtiene de AAA al sumar λ\lambdaλ veces la fila iii a la fila jjj, es decir B=(A1,…,Ai,…,λAi+Aj,…,An)B=(A_1,\dots,A_i,\dots,\lambda A_i+A_j,\dots,A_n)B=(A1​,…,Ai​,…,λAi​+Aj​,…,An​), entonces det⁡ ⁣(B)=det⁡ ⁣(A).\dt{B}=\dt{A}.det(B)=det(A).

Demostraciónmostrar

Aplicamos el axioma A3 (aditividad) a la fila jjj de BBB, que es λAi+Aj\lambda A_i+A_jλAi​+Aj​: det⁡ ⁣(B)=det⁡ ⁣(A1,…,Aii,…,λAij,…,An)+det⁡ ⁣(A1,…,Aii,…,Ajj,…,An).\dt{B}=\dt{A_1,\dots,\overset{i}{A_i},\dots,\overset{j}{\lambda A_i},\dots,A_n} +\dt{A_1,\dots,\overset{i}{A_i},\dots,\overset{j}{A_j},\dots,A_n}.det(B)=det(A1​,…,Ai​i​,…,λAi​j​,…,An​)+det(A1​,…,Ai​i​,…,Aj​j​,…,An​). El segundo sumando es precisamente det⁡ ⁣(A)\dt{A}det(A). En el primero sacamos el escalar λ\lambdaλ de la fila jjj usando el axioma A2: det⁡ ⁣(A1,…,Aii,…,λAij,…,An)=λ det⁡ ⁣(A1,…,Aii,…,Aij,…,An)=λ⋅0=0,\dt{A_1,\dots,\overset{i}{A_i},\dots,\overset{j}{\lambda A_i},\dots,A_n} =\lambda\,\dt{A_1,\dots,\overset{i}{A_i},\dots,\overset{j}{A_i},\dots,A_n}=\lambda\cdot 0=0,det(A1​,…,Ai​i​,…,λAi​j​,…,An​)=λdet(A1​,…,Ai​i​,…,Ai​j​,…,An​)=λ⋅0=0, donde el determinante se anula por el axioma A1, ya que las filas iii y jjj son ambas iguales a AiA_iAi​. Por lo tanto det⁡ ⁣(B)=0+det⁡ ⁣(A)=det⁡ ⁣(A).\dt{B}=0+\dt{A}=\dt{A}.det(B)=0+det(A)=det(A).

Observación 9.3 · Resumen: las tres operaciones elementales

Si A∈Rn×nA\in\Rn{n}{n}A∈Rn×n y BBB se obtiene de AAA aplicando una operación elemental de fila:

Operación Notación Efecto en el determinante
Intercambiar dos filas Fi↔Fj\Fi{i}\leftrightarrow\Fi{j}Fi​↔Fj​ det⁡ ⁣(B)=−det⁡ ⁣(A)\dt{B}=-\dt{A}det(B)=−det(A) (cambia de signo)
Multiplicar una fila por λ≠0\lambda\neq0λ=0 λFi→Fi\lambda\Fi{i}\to\Fi{i}λFi​→Fi​ det⁡ ⁣(B)=λdet⁡ ⁣(A)\dt{B}=\lambda\dt{A}det(B)=λdet(A)
Sumar λFi\lambda\Fi{i}λFi​ a la fila Fj\Fi{j}Fj​ λFi+Fj→Fj\lambda\Fi{i}+\Fi{j}\to\Fi{j}λFi​+Fj​→Fj​ det⁡ ⁣(B)=det⁡ ⁣(A)\dt{B}=\dt{A}det(B)=det(A) (no cambia)

La tercera es la operación estrella: no altera el determinante, así que se puede usar libremente para crear ceros.

9.2 Algoritmo de cálculo por triangularización

Teorema 9.4 · Cálculo del determinante usando operaciones elementales

Sea A∈Rn×nA\in\Rn{n}{n}A∈Rn×n. Para calcular det⁡ ⁣(A)\dt{A}det(A):

  1. Se reduce AAA mediante operaciones elementales de fila hasta llevarla a una matriz triangular superior TTT.

  2. En el proceso se registra cómo cambia el determinante en cada paso:

    • si se intercambian dos filas, el determinante cambia de signo;

    • si se suma un múltiplo de una fila a otra, el determinante no cambia;

    • si en una fila se factoriza una constante (factor común), esa constante «sale» del determinante (axioma A2).

  3. Finalmente, det⁡ ⁣(T)\dt{T}det(T) es el producto de los elementos de su diagonal principal. Deshaciendo los factores registrados se obtiene det⁡ ⁣(A)\dt{A}det(A).

Observación 9.5 · La regla de oro para no equivocarse con los signos

Si durante la reducción se realizaron sss intercambios de filas y se extrajeron los factores λ1,λ2,…,λr\lambda_1,\lambda_2,\dots,\lambda_rλ1​,λ2​,…,λr​ (uno por cada vez que se factorizó una constante de una fila), entonces   det⁡ ⁣(A)=(−1)s λ1λ2⋯λr⋅t11t22⋯tnn  \boxed{\;\dt{A}=(-1)^{s}\,\lambda_1\lambda_2\cdots\lambda_r\cdot t_{11}t_{22}\cdots t_{nn}\;}det(A)=(−1)sλ1​λ2​⋯λr​⋅t11​t22​⋯tnn​​ Recomendación práctica: no dividir filas durante la reducción. Si solo se usa la operación λFi+Fj→Fj\lambda \Fi{i}+\Fi{j}\to\Fi{j}λFi​+Fj​→Fj​ y algún intercambio, no hay factores que recordar y el único cuidado es el signo.

Para recordar del Capítulo 2

  • Intercambiar filas cambia el signo; sumar un múltiplo de una fila a otra no cambia nada; escalar una fila multiplica el determinante por ese escalar.

  • Estrategia: triangularizar usando solo λFi+Fj→Fj\lambda\Fi{i}+\Fi{j}\to\Fi{j}λFi​+Fj​→Fj​ y, si hace falta, intercambios. Así lo único que hay que vigilar es el signo.

  • No dividir filas para «hacer bonito» el pivote: cada división obliga a recordar un factor.

  • Si aparece una fila nula durante la reducción, el determinante es 000.

  • Costo: triangularizar crece como n3n^3n3; los cofactores, como n!n!n!. Para n≥4n\ge4n≥4 la triangularización gana siempre.
